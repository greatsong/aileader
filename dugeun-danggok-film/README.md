# 두근두근 당곡 — 한 줄로 이어지는 한 해

「두근두근 당곡 5분 소개」 슬라이드의 내용을 손그림 셀 애니메이션으로 옮긴 약 105초짜리 장면입니다.
`index.html` 파일 하나로 동작하며, 이미지·외부 라이브러리 없이 캔버스에 직접 그리고 소리도 합성합니다.
그리는 방식은 `moss-giant-engine/`과 같습니다(과슈풍 배경, 잉크 선과 셀 채색, 2콤마 타이밍).

## 실행

```bash
./build.sh        # src/*.js 를 shell.html 에 넣어 index.html 생성 (python3 필요)
```

브라우저로 `index.html`을 열고 재생을 누릅니다. Space 일시정지, ←/→ 5초 이동, F 전체화면, M 음소거.
주소 뒤에 `?t=42.6`을 붙이면 그 시각의 프레임 한 장만 그립니다.

## 장면

| 시각 | 장면 | 슬라이드 |
| --- | --- | --- |
| 0–9초 | 새벽의 학교 언덕, 두근몽 등장 | 표지 |
| 9–28초 | 교무실 책상 네 곳 — 프로그램 담당, 담임, 생기부 담당, 학교 | 학교의 고민 |
| 28–34초 | 흩어진 종이 한 장을 받아 들고, 한 줄을 심음 | — |
| 34–54초 | 들판 길 — 관심, 상담, 후기, 생기부 | 한 학생의 한 해 |
| 54–64초 | 금빛 줄에 걸리는 문서들 | 설계와 기안 · 운영과 정리 |
| 64–72초 | 저녁의 교무실, 교사 PC와 두 가지 안 | 교사 PC 로컬 도구 |
| 72–84초 | 큰 나무 아래 — 후기 한 줄이 새싹으로, 2027 | 결과 보고와 내년 계획 |
| 84–105초 | 노을 진 학교, 연이 날아오름 | 일정 · 마무리 |

## 파일

- `src/1-core.js`, `src/2-brush.js` — 잉크 선·셀 채색, 붓 터치 도구 (엔진 공통)
- `src/3-scenes.js` — 배경 세 곳(학교 언덕, 교무실, 들판) 페인터
- `src/4-mong.js` — 몽 캐릭터 8종과 소품(종이, 팻말, 카드, 말풍선)
- `src/5-main.js` — 장면 연출, 자막(`SUBS`), 소리, 재생기

자막 문구는 `5-main.js`의 `SUBS`에서, 캐릭터 연기는 각 `scene…` 함수에서 고칩니다.

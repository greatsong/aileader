# 두근두근 당곡 — 한 줄로 이어지는 한 해

「두근두근 당곡 5분 소개」 슬라이드를 손그림 셀 애니메이션으로 옮긴 약 135초짜리 장면입니다.
머리에 '낭만당곡' 띠를 두른 학생 두근몽이 담임 선생님, 프로그램 담당 선생님과 어떻게 이어지는지를 한 해의 흐름으로 보여 줍니다.
`index.html` 파일 하나로 동작하며, 이미지·외부 라이브러리 없이 캔버스에 직접 그리고 소리도 합성합니다.
그리는 방식은 `moss-giant-engine/`과 같습니다(과슈풍 배경, 잉크 선과 셀 채색, 2콤마 타이밍).

## 실행

```bash
./build.sh        # src/*.js 를 shell.html 에 넣어 index.html 생성 (python3 필요)
```

브라우저로 `index.html`을 열고 재생을 누릅니다. Space 일시정지, ←/→ 5초 이동, F 전체화면, M 음소거.
주소 뒤에 `?t=42.6`을 붙이면 그 시각의 프레임 한 장만 그립니다.

## 등장인물

두근몽(학생) · 도란(담임) · 뚝딱(프로그램 담당) · 고리(짝) · 아롱(후기 설문) · 초롱(생기부) · 몽실(학교) · 살랑(연)

## 장면

| 시각 | 장면 | 관계 |
| --- | --- | --- |
| 0–9초 | 새벽의 학교 언덕 | — |
| 9–15초 | 첫 상담: "어떤 것에 관심이 있니?" "잘 모르겠어요" | 담임 ↔ 학생, 처음부터 묻는 상담 |
| 15–22초 | 같은 내용을 다시 쓰고, 모집 안내를 들어도 닿지 않음 | 담당 선생님 ↔ 학생, 끊어진 연결 |
| 22–31초 | 그림을 고르고 끌린 이유를 남김, 금빛 줄이 학교로 | 학생 → 담임 (탐색 앱) |
| 31–41초 | 관심을 먼저 보고, 세 부서 프로그램 중 하나를 담아 줌 | 담임 → 학생 (담아 주기) |
| 41–50초 | 교육계획서에서 문서가 이어지고, 모집 안내를 보냄 | 담당 선생님 → 학생 |
| 50–70초 | 수학·정보 융합 프로젝트: 피드백으로 계산 기준과 결론이 바뀜, 관찰 메모 | 담당 선생님 ↔ 학생 ↔ 짝 |
| 70–78초 | 좋았던 점과 아쉬운 점 후기 | 학생 → 담임, 담당 선생님 |
| 78–86초 | 관찰과 결과물로 생기부 초안, 선생님이 읽고 고치고 확인 | 담당 선생님 (AI는 초안만) |
| 86–94초 | 교사 PC에서 두 안 중 고르기 | 담임 |
| 94–102초 | 다음 상담: 경험에서 시작하고, 다음 질문이 나옴 | 담임 ↔ 학생 |
| 102–114초 | 아쉬웠던 한 줄 → AI 개선안 → 승인 → 2027, 새 학생 | 학생 → 담당 선생님 → 다음 학생 |
| 114–135초 | 노을 진 학교, 연이 날아오름 | 모두 |

## 파일

- `src/1-core.js`, `src/2-brush.js` — 잉크 선·셀 채색, 붓 터치 도구 (엔진 공통)
- `src/3-scenes.js` — 배경 세 곳(학교 언덕, 교무실, 들판) 페인터
- `src/4-mong.js` — 몽 캐릭터 8종과 소품(종이, 팻말, 카드, 말풍선)
- `src/5-main.js` — 합성, 공통 장면(새벽·마무리, 문서 흐름, 교사 PC, 나무), 재생기
- `src/6-story.js` — 샷 순서(`SHOTS`), 자막(`SUBS`), 상담·수업·후기·생기부 장면, 소리

자막 문구는 `6-story.js`의 `SUBS`에서, 말풍선과 연기는 각 `scene…` 함수에서 고칩니다.

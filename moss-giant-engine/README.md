# 이끼의 거인 — 손그림 셀 애니메이션 엔진

브라우저 캔버스 하나로, 극장용 2D 애니메이션처럼 보이는 장면을 **절차적으로 그려서** 재생하는 작은 엔진입니다.
이미지·영상·외부 라이브러리를 전혀 쓰지 않고, 빌드 결과는 `index.html` 파일 하나입니다.

들어 있는 장면은 약 73초 분량의 「이끼의 거인」입니다. 안개 낀 숲에서 오래 무릎 꿇고 있던 거대 로봇이 해돋이에 깨어나 하늘로 날아오릅니다.

## 실행

```bash
./build.sh          # src/*.js 를 shell.html 에 넣어 index.html 생성 (python3 필요)
open index.html     # 또는 브라우저로 파일을 직접 열기
```

서버가 필요 없습니다. `index.html`만 따로 복사해도 그대로 동작합니다.

| 키 | 동작 |
| --- | --- |
| Space | 재생 / 일시정지 |
| ← / → | 5초 이동 |
| F | 전체화면 |
| M | 음소거 |
| R | 처음부터 |

주소 뒤에 붙일 수 있는 옵션:

- `?t=44.3` — 해당 시각의 프레임 한 장만 그립니다 (스틸 확인용).
- `?rs=1` — 내부 해상도를 고정합니다 (`1` = 1920×1040, `0.5` = 절반).

## 구조

소스는 번호 순서대로 이어 붙여집니다. 모듈 시스템 없이 전역 함수로 이루어져 있습니다.

| 파일 | 역할 |
| --- | --- |
| `src/1-core.js` | 난수·노이즈·색 유틸, 필압이 변하는 잉크 선(`ink`), 셀 채색(`cel`) |
| `src/2-paint.js` | 과슈풍 배경 페인터 — 숲 4개 층, 안개, 빛줄기, 캐노피 위 하늘 |
| `src/3-robot.js` | 로봇 리그, 키 포즈와 타이밍, 셀 드로잉(녹·이끼·나무 포함) |
| `src/4-fx.js` | 덩굴 물리, 떨어지는 잔해, 먼지, 새, 풀, 화염 |
| `src/5-main.js` | 샷 구성과 카메라, 합성, 하늘 샷, 합성음, 재생기 |
| `shell.html` | 페이지 틀과 시작 화면. `/*__JS__*/` 자리에 스크립트가 들어갑니다 |
| `tools/contact-sheet.js` | 여러 시각의 프레임을 한 장으로 뽑는 점검 도구 (Playwright 필요) |

## 손그림처럼 보이게 하는 방법

**선.** 도형은 제어점 몇 개로 정의하고, 매 드로잉마다 곡선을 촘촘한 꺾은선으로 바꾼 뒤 저주파 노이즈로 살짝 흔듭니다. 선은 굵기가 일정한 획이 아니라 폭이 변하는 리본으로 채워서, 붓 압력이 달라지는 것처럼 보입니다.

**멈춤.** 흔들림의 씨앗은 포즈 값에서 계산합니다. 포즈가 같으면 선도 완전히 같아서, 멈춘 컷에서는 선이 떨리지 않습니다. 포즈가 바뀌는 순간에만 새 그림이 됩니다.

**타이밍.** 화면은 24fps로만 갱신됩니다. 캐릭터와 효과는 평소 2콤마, 일어서는 구간은 3콤마, 발사는 1콤마로 다시 그립니다. 카메라만 매 프레임 움직입니다. 머리·팔·어깨 위 나무는 몸보다 늦게 따라오도록 관절마다 지연을 줍니다.

**채색.** 면은 단색으로 칠하고, 같은 윤곽을 빛 쪽으로 밀어 다시 칠하는 방식으로 딱 떨어지는 그림자를 만듭니다. 햇살이 얼굴을 타고 내려오는 장면은 어두운 팔레트로 한 번, 밝은 팔레트로 한 번 그리고 경계선으로 잘라 붙입니다.

**배경.** 시작할 때 수만 번의 붓 터치를 쌓아 한 번만 그리고, 층마다 다른 속도로 움직여 깊이를 냅니다. 클로즈업에서는 먼 층을 흐리게 씁니다.

**마무리.** 눈·가슴·화염의 빛은 1/8 해상도 층에 그려 부드럽게 얹고, 따뜻한 색 그라데이션과 필름 그레인으로 캐릭터와 배경을 하나로 묶습니다.

## 장면을 고치려면

- **포즈와 연기** — `3-robot.js`의 `POSES`(관절 좌표)와 `POSE_KEYS`(시각·포즈·가감속).
- **샷 길이와 카메라** — `5-main.js`의 `SHOTS`와 `drawForest` 안의 카메라 분기.
- **눈·가슴 불빛, 이끼가 떨어지는 정도** — `5-main.js`의 `eyeAt`, `lidAt`, `chestAt`, `shedAt`.
- **새의 연기** — `4-fx.js`의 `BIRD_KEYS`.
- **소리** — `5-main.js`의 `audioSchedule`. 모든 소리는 Web Audio로 합성합니다.

스틸로 확인할 때는 `?t=` 옵션이나 점검 도구를 씁니다.

```bash
node tools/contact-sheet.js sheet 5 16.5 27 44.3 56.2 66   # sheet.jpg 생성
```

## 성능

GPU 가속이 되는 브라우저를 기준으로 만들었습니다. 시작할 때 프레임 속도를 재서, 느리면 내부 해상도를 0.8 → 0.66 → 0.5배로 낮춥니다. 재생 중에 프레임이 계속 밀려도 한 단계씩 낮춥니다.
배경을 그리는 데 처음에 몇 초가 걸리고, 배경 층이 메모리를 150MB쯤 씁니다.

## 한계

- 로봇은 정면에 가까운 한 방향 리그입니다. 다른 각도는 새 리그를 그려야 합니다.
- 배경은 시드가 고정되어 있어 매번 같은 그림이 나옵니다. 시드는 `paintForest`, `paintSky` 첫 줄에 있습니다.
- 모바일 브라우저에서는 메모리 때문에 열리지 않을 수 있습니다.
